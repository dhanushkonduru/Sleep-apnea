# Sample Audio Clips

This directory contains sample audio files for demonstration purposes.

## Sample Files

### Normal Breathing Sample
- **File**: `normal_breathing.wav`
- **Duration**: 30 seconds
- **Description**: Normal breathing pattern without apnea events
- **Expected Result**: Low risk score, minimal events detected

### Apnea Sample
- **File**: `apnea_sample.wav`
- **Duration**: 45 seconds
- **Description**: Breathing pattern with multiple apnea events
- **Expected Result**: High risk score, multiple events detected

## Usage

These sample files are used in the demo mode of the application. Users can:

1. Click "Try Demo" on the landing page
2. Select a sample file to analyze
3. View the analysis results and spectrogram visualization

## File Format

All sample files are in WAV format with the following specifications:
- **Sample Rate**: 16 kHz
- **Channels**: Mono
- **Bit Depth**: 16-bit
- **Duration**: 10-60 seconds
